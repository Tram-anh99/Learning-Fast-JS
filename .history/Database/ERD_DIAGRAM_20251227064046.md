## Ký Hiệu

- `(PK)` = Primary Key (Khóa chính)
- `(FK)` = Foreign Key (Khóa ngoại)
- `(UNIQUE)` = Ràng buộc duy nhất
- `N-N` = Quan hệ nhiều-nhiều
- `►` = Tham chiếu đến
- `◄` = Được tham chiếu từ

## Các Loại Quan Hệ

### 1-N (One to Many)
```
tinh (1) ──────► (N) huyen
một tỉnh có nhiều huyện
```

### N-N (Many to Many)
```
vung_trong (N) ◄──── vung_cay_trong ────► (N) loai_cay
một vùng có nhiều loại cây, một loại cây ở nhiều vùng
```

### 1-1 (One to One)
```
Hiện tại không có quan hệ 1-1 trong thiết kế này
```
