## ⚡ Các Lệnh Quan Trọng

### Tạo Database
```bash
./setup_database.sh          # Tự động (khuyến nghị)
# hoặc
psql -U postgres -d nongsan_db -f schema_complete.sql  # Thủ công
```

### Kết Nối & Kiểm Tra
```bash
psql -U postgres -d nongsan_db      # Kết nối
\dt nongsan.*                       # Xem danh sách bảng
\dv nongsan.*                       # Xem danh sách views
SELECT * FROM nongsan.v_vung_trong_full;  # Truy vấn mẫu
```

### Backup & Restore
```bash
pg_dump -U postgres -d nongsan_db > backup.sql    # Backup
psql -U postgres -d nongsan_db < backup.sql       # Restore
```

## 📖 Ví Dụ Truy Vấn

### Xem vùng trồng đầy đủ thông tin
```sql
SELECT * FROM nongsan.v_vung_trong_full;
```

### Xem cây trồng với thị trường xuất khẩu
```sql
SELECT 
    vt.ma_vung,
    lc.ten_cay,
    tt.ten_thi_truong
FROM nongsan.vung_thi_truong vtt
JOIN nongsan.vung_cay_trong vct ON vtt.vung_cay_trong_id = vct.id
JOIN nongsan.vung_trong vt ON vct.vung_trong_id = vt.id
JOIN nongsan.loai_cay lc ON vct.loai_cay_id = lc.id
JOIN nongsan.thi_truong tt ON vtt.thi_truong_id = tt.id;
```

### Lịch sử sử dụng phân bón & thuốc
```sql
SELECT 
    lsc.ngay_thuc_hien,
    lhd.ten_loai AS hoat_dong,
    pb.ten_phan_bon,
    tb.ten_thuoc
FROM nongsan.lich_su_canh_tac lsc
LEFT JOIN nongsan.loai_hoat_dong lhd ON lsc.loai_hoat_dong_id = lhd.id
LEFT JOIN nongsan.phan_bon pb ON lsc.phan_bon_id = pb.id
LEFT JOIN nongsan.thuoc_bvtv tb ON lsc.thuoc_bvtv_id = tb.id
ORDER BY lsc.ngay_thuc_hien DESC;
```

## 🔌 Kết Nối Backend

### Flask + psycopg2
```python
import psycopg2
from psycopg2.extras import RealDictCursor

conn = psycopg2.connect(
    host="localhost",
    database="nongsan_db",
    user="postgres",
    password="your_password",
    cursor_factory=RealDictCursor
)
```

### Node.js + pg
```javascript
const { Pool } = require('pg');
const pool = new Pool({
    host: 'localhost',
    database: 'nongsan_db',
```

### Gặp lỗi?

2. Service chưa chạy? → `brew services start postgresql@15`
3. Permission denied? → `chmod +x setup_database.sh`
4. Database exists? → Xóa với `dropdb nongsan_db`
