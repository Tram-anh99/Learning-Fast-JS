## 🎯 Giới Thiệu

**WebGIS Nông Nghiệp Smart** là hệ thống quản lý và truy xuất nguồn gốc nông sản toàn diện, kết hợp công nghệ WebGIS, biểu đồ thống kê, và QR code để cung cấp giải pháp giám sát và quản lý nông nghiệp hiện đại.

### Đặc Điểm Nổi Bật

-    🗺️ **WebGIS tương tác** - Bản đồ Leaflet với polygons vùng trồng
-    📊 **Dashboard thống kê** - Biểu đồ Chart.js đa dạng (Pie, Bar, Line)
-    📱 **QR Code truy xuất** - Quét/tạo mã QR cho từng sản phẩm
-    🔍 **Tìm kiếm thông minh** - Autocomplete, filter theo trạng thái
-    📖 **Nhật ký canh tác** - Ghi chép hoạt động nông nghiệp
-    🎨 **Modern UI** - Glassmorphism, gradient, smooth animations
-    📱 **Mobile Responsive** - Tối ưu cho màn hình 6 inch (360-390px)
-    📲 **Touch-friendly** - Navigation bar với inline labels, touch targets phù hợp

## ✨ Tính Năng Chính

### 1. 🏠 Trang Tra Cứu (HomeView)

-    Tìm kiếm nhanh với autocomplete
-    Filter theo trạng thái (Tất cả/Canh tác/Thu hoạch)
-    Quét mã QR để tra cứu
-    Bản đồ tương tác với polygons
-    Chi tiết vùng trồng với timeline
-    Hiển thị QR code truy xuất

### 2. 📊 Dashboard Quản Lý (QuanLyView)

-    **4 Cards thống kê:** Tổng vùng, Diện tích, Cảnh báo, Thu hồi
-    **Biểu đồ tròn (Pie):** Phân bố thị trường xuất khẩu
-    **Biểu đồ cột (Bar):** Năng suất cây trồng
-    **Biểu đồ đường (Line):** Quan hệ Thị trường × Loại cây
-    **Bản đồ:** Layer control (Sâu bệnh, Dư lượng thuốc)
-    **Bảng dữ liệu:** Danh sách vùng trồng với action buttons
-    **Chi tiết cây trồng:** Thông tin đầy đủ + QR code

### 3. 📖 Nhật Ký Canh Tác (DiaryPage)

-    6 loại hoạt động: Gieo trồng, Bón phân, Phun thuốc, Tưới nước, Thu hoạch, Khác
-    Form nhập linh hoạt (Mô tả, Ngày, Ghi chú)
-    Timeline lịch sử với emoji icons
-    LocalStorage persistence

### 4. 🔐 Truy Xuất Nguồn Gốc (TraceabilityPage)

-    Hiển thị QR code truy xuất
-    Modal glassmorphism đẹp mắt
-    Copy link dễ dàng

## 🚀 Cài Đặt

### Yêu Cầu Hệ Thống

-    Node.js 18.x trở lên
-    npm 9.x hoặc yarn 1.22.x
-    Git

### Bước 1: Clone Repository

```bash
git clone https://github.com/Tram-anh99/Learning-Fast-JS.git
cd Learning-Fast-JS/Frontend
```

### Bước 2: Cài Đặt Dependencies

```bash
npm install
# hoặc
yarn install
```

### Bước 3: Chạy Development Server

```bash
npm run dev
# hoặc
yarn dev
```

Ứng dụng sẽ chạy tại: `http://localhost:5173`

### Bước 4: Build Production

```bash
npm run build
# hoặc
yarn build
```

Build output sẽ nằm trong folder `dist/`

## 🔌 Backend API

### Base URL
```
Development: http://localhost:8000
API Prefix: /api
```

### API Endpoints

#### 🏞️ Farms (Vùng trồng)
```http
GET    /api/farms/                    # List farms (pagination, filter)
GET    /api/farms/{id}                # Get farm detail
POST   /api/farms/                    # Create farm
PUT    /api/farms/{id}                # Update farm
DELETE /api/farms/{id}                # Delete farm
GET    /api/farms/by-code/{ma_vung}  # Get by MSVT code
```

#### 📊 Charts (Thống kê Dashboard)
```http
GET /api/charts/dashboard-stats      # 4 KPIs (farms, area, crops, activities)
GET /api/charts/export-markets       # Pie chart - Thị trường xuất khẩu
GET /api/charts/crop-production      # Bar chart - Sản lượng theo loại cây
GET /api/charts/productivity-trend   # Line chart - Xu hướng năng suất
GET /api/charts/farm-status          # Pie chart - Trạng thái vùng
GET /api/charts/activity-timeline    # Line chart - Hoạt động theo tháng
```

#### 📖 Diary (Nhật ký canh tác)
```http
GET    /api/diary/                    # List diary entries
GET    /api/diary/{id}                # Get entry detail
POST   /api/diary/                    # Create entry
PUT    /api/diary/{id}                # Update entry
DELETE /api/diary/{id}                # Delete entry
GET    /api/diary/activity-types/    # List activity types (6 types)
```

#### 🌿 Fertilizers (Danh mục phân bón) ⭐ NEW
```http
GET  /api/fertilizers/categories/    # List loại phân bón (Đạm, Lân, Kali, Hữu cơ)
POST /api/fertilizers/categories/    # Create loại phân bón
GET  /api/fertilizers/               # List phân bón (search, filter, pagination)
GET  /api/fertilizers/{id}           # Get phân bón detail
POST /api/fertilizers/               # Create phân bón
PUT  /api/fertilizers/{id}           # Update phân bón
DELETE /api/fertilizers/{id}         # Delete phân bón
```

#### 💊 Pesticides (Danh mục thuốc BVTV) ⭐ NEW
