## 🎯 Giới Thiệu

Hệ thống quản lý nông nghiệp hiện đại, toàn diện với khả năng **truy xuất nguồn gốc nông sản** thông qua **QR code**. Hệ thống giúp:

- ✅ **Nông dân:** Quản lý vùng trồng, ghi nhật ký canh tác hàng ngày
- ✅ **Quản lý:** Giám sát, thống kê, báo cáo toàn bộ hoạt động nông nghiệp
- ✅ **Người tiêu dùng:** Quét QR để xem nguồn gốc, lịch sử canh tác sản phẩm
- ✅ **Cơ quan nhà nước:** Giám sát, cấp chứng nhận VietGAP, GlobalGAP

### 🏆 Đặc Điểm Nổi Bật

- 🗺️ **Bản đồ GIS tích hợp:** Hiển thị vùng trồng trên bản đồ với GeoJSON
- 📱 **QR Code truy xuất:** Minh bạch 100% quy trình canh tác
- 📊 **Dashboard trực quan:** Biểu đồ thống kê real-time
- 🌱 **Nhật ký canh tác:** Ghi chép chi tiết mọi hoạt động
- 🏭 **Quản lý cơ sở:** Cơ sở đóng gói, phân bón, thuốc BVTV, giống
- 📜 **Chứng nhận:** Quản lý VietGAP, GlobalGAP, Organic certificates

## ✨ Tính Năng

### 1. Quản Lý Vùng Trồng
- Thêm/Sửa/Xóa vùng trồng
- Gắn tọa độ địa lý (GPS coordinates)
- Quản lý diện tích, loại cây trồng
- Phân quyền theo chủ sở hữu

### 2. Nhật Ký Canh Tác
- Ghi hoạt động: Gieo trồng, Bón phân, Phun thuốc, Tưới nước, Thu hoạch
- Lưu chi tiết: Phân bón sử dụng, Thuốc BVTV, Giống cây, Liều lượng
- Timeline hiển thị lịch sử đầy đủ
- Người thực hiện, Ngày giờ chính xác

### 3. Bản Đồ GIS
- Hiển thị vùng trồng trên bản đồ tương tác (Leaflet.js)
- GeoJSON Polygon/Line rendering
- Filter theo Tỉnh/Huyện/Xã
- Click vào polygon để xem thông tin chi tiết
- Layer control (Provinces, Districts, Communes, Farms)

### 4. Truy Xuất Nguồn Gốc (QR Code)
- Tạo QR code cho mỗi vùng trồng/sản phẩm
- Consumer quét QR → xem đầy đủ thông tin:
  - Tên vùng trồng, Địa điểm, Diện tích
  - Loại cây trồng, Giống
  - Timeline hoạt động canh tác (từ gieo trồng → thu hoạch)
  - Phân bón, Thuốc BVTV đã sử dụng
  - Chứng nhận (VietGAP, Organic...)
  - Chủ sở hữu, Liên hệ
- Public access (không cần đăng nhập)

### 5. Dashboard & Thống Kê
- KPI Cards: Tổng vùng trồng, Diện tích, Cơ sở, Hoạt động
- Bar Chart: Cơ sở theo loại hình
- Pie Chart: Phân bố trạng thái vùng trồng
- Line Chart: Xu hướng năng suất theo tháng
- Export báo cáo Excel/PDF

### 6. Quản Lý Cơ Sở Sản Xuất
- Cơ sở đóng gói sản phẩm
- Cơ sở sản xuất phân bón
- Cơ sở sản xuất thuốc BVTV
- Cơ sở giống cây trồng
- Gắn tọa độ địa lý, Thông tin liên hệ

### 7. Danh Mục
- **Cây trồng:** 100+ loại cây (Lúa, Cà phê, Tiêu, Cao su...)
- **Phân bón:** NPK, Hữu cơ, Vi sinh...
- **Thuốc BVTV:** Thuốc trừ sâu, Thuốc diệt cỏ, Thuốc diệt nấm
- **Giống cây:** Giống bảo hộ, Giống địa phương
- Quản lý thành phần, Hàm lượng, Liều lượng khuyến nghị

```bash
# 1. Clone repository
git clone https://github.com/Tram-anh99/Learning-Fast-JS.git

# 2. Setup database
createdb -U postgres nongsan_db
# Import schema hoặc restore backup nếu có

./start.sh
```

**Startup script sẽ tự động:**
- ✅ Check prerequisites (Python, Node.js, PostgreSQL)
- ✅ Install dependencies
- ✅ Start Backend (port 8000)
- ✅ Start Frontend (port 5173)
- ✅ Open browser

### 📝 Manual Setup (Chi tiết)

#### 1. Setup Database

```bash
# Create database
createdb -U postgres nongsan_db

# Import schema (if available)
psql -U postgres -d nongsan_db -f Database/nongsan_schema.sql

# Or restore from backup
cd Database
./backup_database.sh restore backups/nongsan_db_YYYYMMDD.sql.gz
```

#### 2. Setup Backend

```bash
cd Backend

# Option 1: Using virtual environment
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements-minimal.txt

# Option 2: Using Conda (Recommended)
conda create -n agri python=3.11
conda activate agri
pip install -r requirements-minimal.txt

# Configure environment
cp .env.example .env
nano .env  # Edit DATABASE_URL
```

**`.env` file:**
```env
DATABASE_URL=postgresql://postgres:your_password@localhost:5432/nongsan_db
API_TITLE=Agricultural Management API
API_VERSION=2.0
CORS_ORIGINS=http://localhost:5173
```

#### 3. Setup Frontend

```bash
cd Frontend
npm install
```

#### 4. Run Application

**Terminal 1 - Backend:**
```bash
cd Backend
source venv/bin/activate  # or: conda activate agri
uvicorn app:app --reload --port 8000
```

**Terminal 2 - Frontend:**
```bash
cd Frontend
npm run dev
```

### 📱 Quét QR Code (Workflow)

1. Consumer mua sản phẩm có QR code
2. Mở camera điện thoại → Quét QR
3. QR chứa link: `https://yourdomain.com/truy-xuat/VT000123`
4. Browser mở link → Hiển thị thông tin truy xuất
5. Consumer xem:
   - Thông tin vùng trồng
   - Lịch sử canh tác chi tiết
   - Phân bón, thuốc BVTV đã dùng
   - Chứng nhận VietGAP, Organic...

```
tinh (Province)
 └── huyen (District)
      └── xa (Commune)
           └── vung_trong (Farm)
                ├── vung_cay_trong (Crop Areas)
                │   └── loai_cay (Crop Types)
                ├── toa_do_vung (Coordinates)
                ├── lich_su_canh_tac (Activity History)
                │   ├── loai_hoat_dong (Activity Types)
                │   ├── phan_bon (Fertilizers)

                │   └── giong_cay (Seeds)

co_so (Facilities)

 ├── co_so_thuoc_bvtv (Pesticide)
 └── co_so_giong (Seed)

to_chuc_ca_nhan (Organizations/Individuals)
thi_truong (Markets)
vung_trong_thi_truong (Farm-Market relations)
```

### 📋 Key Tables

#### `vung_trong` (Farms) - Core Table
```sql
id              SERIAL PRIMARY KEY
ma_vung         VARCHAR(50) UNIQUE NOT NULL  -- QR code
ten_vung        VARCHAR(200) NOT NULL
dien_tich       DECIMAL(10,2)                 -- hectares
tinh_id         INT → tinh(id)
huyen_id        INT → huyen(id)
xa_id           INT → xa(id)
chu_so_huu_id   INT → to_chuc_ca_nhan(id)
trang_thai_id   INT
x, y            DECIMAL(10,6)                 -- GPS coordinates
```

#### `lich_su_canh_tac` (Activity History)
```sql
id                  SERIAL PRIMARY KEY
vung_trong_id       INT → vung_trong(id)
loai_hoat_dong_id   INT → loai_hoat_dong(id)
ngay_thuc_hien      DATE
chi_tiet            TEXT
phan_bon_id         INT → phan_bon(id)
thuoc_bvtv_id       INT → thuoc_bvtv(id)
giong_id            INT → giong_cay(id)
lieu_luong          VARCHAR(50)
don_vi              VARCHAR(20)
```

### Base URL

```
Development: http://localhost:8000
API Prefix: /api
```

### API Endpoints

#### 🏞️ Farms (Vùng trồng)

```http
GET    /api/farms/                    # List farms (pagination, filter)
GET    /api/farms/{id}                # Get farm detail
POST   /api/farms/                    # Create farm
PUT    /api/farms/{id}                # Update farm
DELETE /api/farms/{id}                # Delete farm
GET    /api/farms/by-code/{ma_vung}  # Get by MSVT code
```

#### 📊 Charts (Thống kê Dashboard)

```http
GET /api/charts/dashboard-stats      # 4 KPIs (farms, area, crops, activities)
GET /api/charts/export-markets       # Pie chart - Thị trường xuất khẩu
GET /api/charts/crop-production      # Bar chart - Sản lượng theo loại cây
GET /api/charts/productivity-trend   # Line chart - Xu hướng năng suất
GET /api/charts/farm-status          # Pie chart - Trạng thái vùng
GET /api/charts/activity-timeline    # Line chart - Hoạt động theo tháng
```

#### 📖 Diary (Nhật ký canh tác)

```http
GET    /api/diary/                    # List diary entries
GET    /api/diary/{id}                # Get entry detail
POST   /api/diary/                    # Create entry
PUT    /api/diary/{id}                # Update entry
DELETE /api/diary/{id}                # Delete entry
GET    /api/diary/activity-types/    # List activity types (6 types)
```

```http
POST /api/fertilizers/               # Create phân bón
```
