-    **Vue Router 4.5.0** - Routing giữa các trang
-    **QRCode.vue 3.5.1** - Tạo mã QR

## 🎯 Tính năng chính

### 1. **Bản đồ WebGIS** (HomeView)

-    Tra cứu vùng trồng trên bản đồ tương tác
-    Lọc theo trạng thái (canh tác, thu hoạch, đã thu hoạch)
-    Tìm kiếm nhanh với autocomplete
-    Quét/nhập mã QR để tra cứu
-    Chi tiết vùng với timeline nhật ký

### 2. **Quản lý Vùng trồng** (QuanLyView)

-    Dashboard với thống kê tổng quan
-    Biểu đồ: Pie, Bar, Line charts
-    Bản đồ với layer control (sâu bệnh, dư lượng thuốc)
-    Bảng danh sách vùng với filter & export
-    Chi tiết cây trồng & lịch sử canh tác
-    Mã QR truy xuất nguồn gốc

### 3. **Nhật ký Canh tác** (DiaryPage)

-    Ghi chép hoạt động theo loại (gieo trồng, bón phân, phun thuốc...)
-    Chọn từ danh mục Phân bón & Thuốc BVTV ⭐ NEW
-    Lịch sử hoạt động theo timeline
-    FAB button để thêm nhanh
-    **Endpoints:** `/api/diary/`, `/api/fertilizers/`, `/api/pesticides/`

### 4. **Truy xuất Nguồn gốc** (TraceabilityPage)

-    Hiển thị thông tin chi tiết nông sản
-    Mã QR để chia sẻ/scan ⭐ NEW
-    Trang công khai cho khách hàng ⭐ NEW
-    **Endpoints:** `/api/qr/generate/`, `/api/qr/trace/`

## � Backend API Integration

### API Base URL

```javascript
const API_URL = "http://localhost:8000/api";
```

### Các endpoint đã integrate:

-    ✅ `/farms/*` - Vùng trồng (CRUD)
-    ✅ `/charts/*` - Dashboard thống kê
-    ✅ `/diary/*` - Nhật ký canh tác
-    ✅ `/fertilizers/*` - Danh mục phân bón ⭐ NEW
-    ✅ `/pesticides/*` - Danh mục thuốc BVTV ⭐ NEW
-    ✅ `/qr/generate/` - Tạo mã QR ⭐ NEW
-    ✅ `/qr/trace/` - Truy xuất công khai ⭐ NEW

### Usage Examples

**1. Lấy danh sách loại phân bón:**

```javascript
const response = await fetch(`${API_URL}/fertilizers/categories/`);
const fertilizers = await response.json();
```

**2. Lấy danh sách thuốc BVTV:**

```javascript
const response = await fetch(`${API_URL}/pesticides/?search=Abamectin`);
const pesticides = await response.json();
```

**3. Tạo mã QR cho vùng trồng:**

```javascript
const response = await fetch(`${API_URL}/qr/generate/MSVT001?size=300`);
const qrData = await response.json();
// qrData.qr_code = "data:image/png;base64,..."
```

**4. Lấy thông tin truy xuất công khai:**

```javascript
const response = await fetch(`${API_URL}/qr/trace/MSVT001`);
const traceability = await response.json();
// Returns: farm, owner, status, coordinates, history
```
