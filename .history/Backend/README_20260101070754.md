# 🌾 Agriculture Management - FastAPI Backend

> API server kết nối PostgreSQL với FastAPI framework

## 🚀 Quick Start

### 1. Cài Đặt Dependencies

```bash
# Tạo virtual environment (khuyến nghị)
python3 -m venv .venv
source .venv/bin/activate  # macOS/Linux
# .venv\Scripts\activate   # Windows

# Cài packages
pip install -r requirements-minimal.txt
```

### 2. Cấu Hình Database

Sửa file `.env`:

```bash
DB_HOST=localhost
DB_PORT=5433          # Port PostgreSQL của bạn
DB_NAME=postgres      # Database name
DB_USER=postgres      # Username
DB_PASSWORD=123456    # Password (hoặc 000000)
DB_SCHEMA=nongsan     # Schema name
```

### 3. Test Kết Nối

```bash
./test_db.sh
```

### 4. Khởi Động Server

```bash
./start.sh

# Hoặc thủ công:
python app.py

# Hoặc dùng uvicorn:
uvicorn app:app --reload
```

Server chạy tại: **http://localhost:8000**

## 🔌 API Endpoints

### 🏥 Health Check

```
GET  /api/health
```

### 🌾 Farms (Vùng Trồng)

```
GET    /api/farms              # List all farms (with pagination)
GET    /api/farms/{id}         # Get farm details
GET    /api/farms/by-code/{ma} # Get farm by MSVT code
POST   /api/farms              # Create new farm
PUT    /api/farms/{id}         # Update farm
DELETE /api/farms/{id}         # Delete farm
```

### 📊 Charts & Statistics

```
GET /api/charts/dashboard-stats    # Dashboard overview
GET /api/charts/export-markets     # Export markets pie chart
GET /api/charts/crop-production    # Crop production bar chart
GET /api/charts/productivity-trend # Productivity line chart
GET /api/charts/farm-status        # Farm status distribution
GET /api/charts/activity-timeline  # Activity timeline
```

### 📝 Diary (Nhật Ký Canh Tác)

```
GET    /api/diary                 # List diary entries
GET    /api/diary/{id}            # Get entry details
POST   /api/diary                 # Create new entry
PUT    /api/diary/{id}            # Update entry
DELETE /api/diary/{id}            # Delete entry
GET    /api/diary/activity-types  # List activity types
```

### 🌿 Fertilizers (Danh Mục Phân Bón) ⭐ NEW

```
GET  /api/fertilizers/categories/    # List loại phân bón
POST /api/fertilizers/categories/    # Create loại phân bón
GET  /api/fertilizers/               # List phân bón (search, filter, pagination)
GET  /api/fertilizers/{id}           # Get phân bón detail
POST /api/fertilizers/               # Create phân bón
PUT  /api/fertilizers/{id}           # Update phân bón
DELETE /api/fertilizers/{id}         # Delete phân bón
```

**Query Parameters:**
- `search` - Search by tên, mã phân bón
- `loai_phan_bon_id` - Filter by loại
- `skip`, `limit` - Pagination

### 💊 Pesticides (Danh Mục Thuốc BVTV) ⭐ NEW

```
GET  /api/pesticides/groups/         # List nhóm thuốc
POST /api/pesticides/groups/         # Create nhóm thuốc
GET  /api/pesticides/                # List thuốc (search, filter, pagination)
GET  /api/pesticides/{id}            # Get thuốc detail
POST /api/pesticides/                # Create thuốc
PUT  /api/pesticides/{id}            # Update thuốc
DELETE /api/pesticides/{id}          # Delete thuốc
```

**Query Parameters:**
- `search` - Search by tên, mã, tên hoạt chất
- `nhom_thuoc_id` - Filter by nhóm
- `trang_thai_su_dung` - Filter by status (Được phép, Hạn chế, Cấm)
- `skip`, `limit` - Pagination

### 📱 QR & Traceability (Truy Xuất Nguồn Gốc) ⭐ NEW

```
GET /api/qr/generate/{ma_vung}?size=300  # Generate QR code (base64 PNG)
GET /api/qr/trace/{ma_vung}               # Public traceability info (no auth)
```

**Features:**
- QR code generation với base64 PNG output
- Public traceability page (không cần authentication)
- Mobile-optimized response format
- Bao gồm: farm info, owner, status, coordinates, history (10 entries)

## 🐛 Troubleshooting

### ❌ Database Connection Failed

```bash
# 1. Kiểm tra PostgreSQL có chạy không
brew services list | grep postgres

# 2. Test connection bằng psql
psql -h localhost -p 5433 -U postgres -d postgres

# 3. Chạy test script
./test_db.sh
```

### ❌ Module Not Found

```bash
# Cài lại dependencies
pip install -r requirements-minimal.txt

# Kiểm tra virtual environment
which python  # Should show .venv/bin/python
```

### ❌ Port Already in Use

```bash
# Tìm process đang dùng port 8000
lsof -i :8000

# Kill process
kill -9 <PID>

# Hoặc dùng port khác
uvicorn app:app --port 8001
```

## 📊 Database Schema

### Current Models (7 models implemented)

1. **VungTrong** (Farm Zones) - 19 columns
   - MSVT code, name, area, address, crop type, status
   - Relationships: ToaDoVung, LoaiCay, ToChucCaNhan, TrangThaiVung

2. **ToaDoVung** (Coordinates) - 5 columns
   - Latitude, longitude, order, farm reference

3. **LoaiCay** (Crop Types) - 11 columns
   - Crop name, category, cultivation method, seasons
   - Relationships: VungCayTrong

4. **ToChucCaNhan** (Organizations/Owners) - 11 columns
   - Organization/individual info, contact details
   - Relationships: VungTrong

5. **TrangThaiVung** (Farm Status) - 5 columns
   - Status types: Chờ duyệt, Hoạt động, Cảnh báo, Thu hồi
   - Color codes for UI

6. **PhanBon** (Fertilizers) - 7 columns ⭐ NEW
   - Fertilizer code, name, composition, unit
   - Relationships: LoaiPhanBon, LichSuCanhTac
   - Categories: Đạm, Lân, Kali, Hữu cơ

7. **ThuocBVTV** (Pesticides) - 9 columns ⭐ NEW
   - Pesticide code, name, active ingredient, formulation
   - Usage status: Được phép, Hạn chế, Cấm
   - Relationships: NhomThuocBVTV, LichSuCanhTac
   - Groups: Trừ sâu, Diệt nấm, Diệt cỏ, etc.
